# Commercial roadmap

## Phase 1 — validate the loop

- define a separate, explicit opt-in newsletter that is not associated with invitations
- connect the branded domain and complete trademark clearance
- measure create → share → open → response → remix
- add automated expiry cleanup and retention evidence
- improve accessibility, localization QA and abuse tooling
- run small creator/influencer pilots using sponsor packs

## Phase 2 — low-friction revenue

- test paid visual personalization and advanced creator statistics
- add Apple Pay/Google Pay through a hosted Stripe flow only after explicit activation
- sell branded sponsor packs to venues and creators
- evaluate opt-in recovery only if it preserves the current no-account, email-not-stored privacy model

## Phase 3 — defensible platform

- publish a versioned, authenticated SDK/API offering
- build privacy-thresholded country and cohort trend reports
- add pack authoring, customer tenancy and usage metering
- document dataset provenance, consent, retention and licensing rights

## Exit-readiness gates

- clean chain of title and contributor agreements
- registered brand/domain ownership in the legal entity
- reproducible deployment and disaster recovery
- cohort-level traction and revenue evidence
- dependency and data-protection review
- buyer-safe credential and operations handover

The roadmap is directional. Payment, push notification and WhatsApp Business code must remain disabled until credentials, policies, consent and support procedures are ready.
